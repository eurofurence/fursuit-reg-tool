# Catch-Em-All

The mobile-first game where attendees "catch" fursuiters by typing the 5-character code printed on
their badge. Read this before touching `routes/catch-em-all.php`, `app/Domain/CatchEmAll/` or the
`app/Models/FCEA/` ranking models.

## Where it lives

The game is served from its own subdomain - `config/fcea.php` `domain` (`CATCH_DOMAIN`, e.g.
`catch.fursuit-reg-tool.test`), which is why it has its own auth flow rather than sharing the main
site's session routes.

- `routes/catch-em-all.php` - all game routes
- `app/Domain/CatchEmAll/Controllers/GameController.php` - every routed action
- `resources/js/Pages/CatchEmAll/` - the current frontend; `resources/js/Pages/FCEA/` is the older
  dashboard interface
- `config/fcea.php` - domain, code length, rate limit, rarity thresholds

## Routes

Three middleware tiers, in `routes/catch-em-all.php`:

| Tier | Middleware | Routes |
|---|---|---|
| Public | none | `manifest.json`, `sw.js` (PWA), `auth.login`, `auth.login.callback`, `auth.logout`, `auth.logout.callback` |
| Authed | `catch-auth:web` | `introduction`, `introduction.complete` |
| In-game | `catch-auth:web` + `catch-introduction` | `catch` (`/`), `catch.submit` (`POST /catch`), `leaderboard`, `achievements`, `collection`, `profile` |

The introduction tier exists so a first-time player is walked through the game before the
`catch-introduction` middleware will let them at the rest of it.

## Rarity

`App\Domain\CatchEmAll\Enums\FursuitRarity` - `COMMON`, `UNCOMMON`, `RARE`, `EPIC`, `LEGENDARY`,
each carrying its own label, color, gradient and icon for the UI.

Rarity is **derived from how common the species is**, not assigned by hand: `UserCatch` counts the
fursuits of that species and compares against the thresholds in `config/fcea.php`
(`species_rarity_threshold_uncommon` / `_rare` / `_epic` / `_legendary`, defaults 5 / 10 / 20 / 50).
Anything under the lowest threshold is `COMMON`.

## Achievements

`app/Domain/CatchEmAll/Achievements/` holds one class per achievement, registered through
`Utils/AchievementRegister.php` and built by `Utils/AchievementFactory.php`; most extend
`Abstract/SimpleAchievement.php`. `Achievements/Special/` covers the ones awarded by special codes
rather than by catching (see `Models/SpecialCode.php`, `Models/UserSpecialCatch.php` and
`Enums/SpecialCodeType.php`). Progress lands in `Models/UserAchievement.php`.

## Rankings

Leaderboard rows live in `App\Models\FCEA\UserCatchRanking`, which holds **both** user and fursuit
rankings in one table. They are rebuilt by the static methods on
`App\Http\Controllers\FCEA\DashboardController` (`refreshRanking`, `refreshUserRanking`,
`refreshFursuitRanking`), called from `RefreshFceaRankingsCommand` (`fcea:refresh-rankings`,
scheduled every 15 minutes) and `UpdateRankingsJob`.

That controller is no longer routed - it is kept for those ranking statics. Deleting it takes the
leaderboard refresh with it.

## Catch codes and anti-abuse

- Codes are generated by `fursuit:create-catch-code` (`--purge-all`, `--regen-unprinted`) and are
  `fcea.fursuit_catch_code_length` characters long (default 5)
- Submissions are rate-limited to `fcea.fursuit_catch_attempts_per_minute` per user (default 20),
  answering `429` past that, so a short code cannot be brute-forced
- Every attempt, successful or not, is written to `App\Models\FCEA\UserCatchLog`
